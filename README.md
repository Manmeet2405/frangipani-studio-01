# Studio Frangipani

Local setup instructions are in [`RUN_LOCALLY.md`](./RUN_LOCALLY.md).

This project currently works as a **frontend-first prototype**:
- Main app: React + Tailwind + shadcn UI
- Optional backend template: FastAPI + MongoDB
- Current Studio Frangipani experience is driven by mock/local browser state, so you can run the frontend by itself
